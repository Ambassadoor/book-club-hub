# Book Club Hub

A modern React + Typescript + Vite application for exploring and managing book clubs and personal reading data. 

## Tech Stack

**Frontend:**
- React 19 + Typescript
- Vite
- Material-UI (MUI)
- Tailwind CSS v4
- React Router

**Dev Tools:**
- ESLint + Prettier (linting and formatting)
